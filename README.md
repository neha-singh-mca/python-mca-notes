## Day 2 - Modules, Pip & Comments

What is a Module?
A module is a file containing python code (functions, variables) that you can include in your program. Like a toolbox.
Ex: math module for maths, random for random numbers.
Usage: import math

What is Pip?
Pip is package manager for python.
Used to install external modules which are not pre-installed.
Command: pip install module-name
Example: pip install flask

Comments in Python:
Comments are lines that the computer ignores. For human understanding.
Single line comment starts with #
Ex: # This is a comment

REPL: Read-Eval-Print Loop - The python terminal where you can run code instantly.
